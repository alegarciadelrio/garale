## Overview
Garale is a specialized software tool designed to calculate and optimize the performance of two-stroke engines. 
This project was initiated in collaboration with the CiclosArgentinos Forum in 2011 and is developed using Java with Eclipse IDE.

The software provides various calculations and optimizations to help mechanics and enthusiasts enhance the performance of their two-stroke engines through precise measurements and adjustments.

## Features:

-Optimal transfer height.

-Displacement of the cylinder.

-Optimal carburetor.

-The right area for the flapper.

-Compression relationship.

-Cylinder lid down.

-Surface time.

-Exhaust pipe.

-Bottle volume for YEIS.

-YEIS rpm operation.

-YEIS optimal hose.

## Requirements
- Java Runtime Environment (JRE) 8 or higher
- Minimum 512MB RAM
- Windows, macOS, or Linux operating system
- Screen resolution of 1024x768 or higher (recommended)

## Usage
1. Download the application from the link below
2. Extract the downloaded file to a directory of your choice
3. Run the application by double-clicking on the JAR file or using the command:
   ```
   java -jar javapipe.jar
   ```
4. Use the menu to navigate to the specific calculation tool you need
5. Input the required measurements and parameters
6. View the calculated results and recommendations for optimizing your two-stroke engine
